系统设置

与工具栏那两枚按钮、快捷键 3 / 2 / 4 是同一个开关，改完就存住；四图 2×2 工具栏上没放按钮，只能从这里选。

开启后任一窗的缩放平移会复制到其它可见窗，载入新图也直接沿用同一区域。单图布局下只剩一个窗，这一项没有作用。

双指滚动按这里选的行为走；触控板捏合（pinch）始终缩放，不受这一项影响。

查看历史

侧栏默认列「最近看过」：打开 / 拖入 / 粘贴 / 在列表里逐张翻看 / 在传输里放大看过，都算看过；同一张只留一条，重复查看只置顶，最多 100 条。翻看时列表不会回跳（只更新记录），切走再切回来看到的就是最新顺序。文件被移走 / 改名时那一行只会标灰，不会自动删掉（外置盘没挂载也是「读不到」，不能就当没看过给抹了），要清就整份清。

选一台设备开对话框

已登记的设备与局域网里发现的设备合在一起，点一下开一个框；同一台可以重复点、开好几个。已经有的那几个去左边列表里点。

待发送
松开即放入待发送 支持一次拖多个，文件、图片、文件夹都行；放进去之后还能再改，点发送才发出去
配对设置

口令只存本机，用于互认与请求签名。局域网内是明文传输，别用来传敏感文件。

本机接收

响的是本进程，窗口关着也响；一整个文件夹收完只响一声，同一条消息重发不重响。

只影响新收到的文件；之前收到的留在老目录里，聊天记录照样能预览、另存、定位。改到外置盘或网络盘上之后，盘一拔掉那些气泡就打不开了。

新收到的文件落在 …。一个文件夹整批发过来时，它是上面这个目录里的一个同名子文件夹；改选项只影响之后收到的，已经收好的不会被搬动。

mDNS 被网络策略屏蔽时的兜底；端口留空会从 45789 起逐个试探。可以同时添加多台，每台一个对话框。

备注只存本机、只改本机显示（会话栏 / 顶栏 / 新建聊天的默认名），对端那边看不到任何变化。

解绑只是不再主动发给它，而且不会再自动连回来 —— 要恢复得在上面的候选里点一下或再填一次 IP。聊天历史与收到的文件都留着。Windows 首次监听会弹防火墙提示，必须勾「允许访问（私有网络）」。
